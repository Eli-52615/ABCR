# R2 真批 · 非技术人员照抄操作说明

> 目标：在一台带显卡（GPU）的云电脑上，跑一次真 7B 模型的 golden10 基准批，让系统自动出「R2 过门」判定。
> 全程只需**照抄命令**。唯一需要一点点动手的是「租云电脑 + 传文件」，下面给了最省心的具体路径。
> 预算：约 ¥20–30（跑完记得关机停止扣费）。

---

## 先确认你手上有这 3 样

1. **这个项目文件夹**（就是含本文件的 `abcr` 仓库；整个文件夹）。
2. **一个 DeepSeek 的 API key**（判分要用）——已经填在项目里的 `.env` 文件里，你不用管。
3. **能上网的电脑 + 微信/支付宝**（租 GPU 付费用）。

---

## 第一步：租一台带 GPU 的云电脑（约 5 分钟）

推荐 **AutoDL**（autodl.com，国内、网页操作、按小时计费、自带 PyTorch，最省心）：

1. 注册登录 → 充值 ¥50（够用）。
2. 「算力市场」→ 选一张 **24GB 显存**的卡（**RTX 4090** 或 **A5000** 都行，约 ¥2/小时）。
3. 「镜像」选带 **PyTorch 2.x**（有就选，省得自己装 torch）。
4. 点「立即创建」→ 开机后点「JupyterLab」进去 → 左上角 `+` → 开一个 **Terminal（终端）**。
   往后所有命令都敲在这个黑框终端里。

> 不用 AutoDL 也行：任何能给你一个「24GB 显卡 + Linux 终端」的服务都可以（RunPod、阿里云 GPU 等）。

---

## 第二步：把项目文件夹传上去（约 5 分钟）

在 JupyterLab 左侧文件区，把你本地的 `abcr` 文件夹**打包上传**：

- 本地先把 `abcr` 压成一个 `abcr.zip`（右键压缩即可）。
- JupyterLab 左侧文件区 → 上传按钮 → 选 `abcr.zip`。
- 回到终端，解压并进目录：
  ```bash
  cd ~/autodl-tmp 2>/dev/null || cd ~      # AutoDL 数据盘目录；没有就用 home
  unzip -q abcr.zip
  cd abcr                                   # 若解压出的是 abcr-xxx，就 cd 那个名字
  ```

## 第三步：装环境（复制粘贴，约 10 分钟，多在下模型）

```bash
# 1) 判分依赖 + 真模型依赖（若镜像已带 torch，torch 那行会秒过）
#    注：用 `python -m pip` 而非裸 `pip`——有些机器 pip 不在 PATH，但 python 能用。
python -m pip install torch transformers "openai==1.70.0" "backoff==2.2.1" "pyyaml==6.0.2"

# 2) 让 shell 认识项目 + 读你的 key
export PYTHONPATH=src
set -a; source .env; set +a

# 3) 下模型（约 15GB，走国内镜像；只需一次）
#    ⚠️ 必须先关掉 HF 的 Xet 加速协议——国内镜像不支持它，不关会卡在 0 字节报 401。
python -m pip uninstall -y hf_xet 2>/dev/null || true   # 卸掉 Xet 客户端，彻底断了它的念想
export HF_HUB_DISABLE_XET=1
export HF_ENDPOINT=https://hf-mirror.com
python -c "from transformers import AutoModelForCausalLM, AutoTokenizer; \
AutoModelForCausalLM.from_pretrained('Qwen/Qwen2.5-7B-Instruct', torch_dtype='bfloat16'); \
AutoTokenizer.from_pretrained('Qwen/Qwen2.5-7B-Instruct'); print('模型就绪')"

# 4) 判分 key 自检（看到 verdict.ok=true 就对了）
python scripts/b_judge_smoke.py && echo "key 正常"
```

看到「模型就绪」和「key 正常」就可以进下一步。任一没出现，见文末「出问题怎么办」。

---

## 第四步：跑 R2 批（一条命令）

```bash
bash scripts/run_r2_batch.sh
```

这条命令会自动依次：生成并签批次 → 真 7B 逐题跑 → 独立复算 → 六项审计 → 打包独立复算。
真跑约 10–30 分钟（在逐题推理，正常）。**中途别关窗口。**

---

## 第五步：看结果（判 R2 过没过）

命令跑完，最后会打印一个方框。**同时满足这两条 = R2 硬门过**：

1. `a_audit` 的 **item1~5 全部 PASS**；
2. `agreement_deterministic_v1=1.0` **且** `agreement_rescore_v1=1.0`。

> 关于 **item6（成本对账）**：它一开始会 FAIL，因为还没告诉系统「这次 GPU 花了多少钱」。
> 方框里会给你一行「补记实耗」命令，把 `<实耗元>` 换成实际花费（比如 15），跑一下、再 `--items 6` 复审即可 PASS。
> item6 不影响 R2 核心判定，补不补都行。

## 出问题怎么办（对症照抄）

| 现象 | 处理 |
|---|---|
| `pip: command not found` | 用 `python -m pip ...` 代替裸 `pip ...`（同一个 Python，换个调用方式） |
| `python: command not found` | 用 `python3` 代替 `python`；或 `PY=python3 bash scripts/run_r2_batch.sh` |
| 下模型很慢/中断 | 重跑第三步第 3 条命令即可（会断点续传）；确认 `HF_ENDPOINT` 已 export |
| **下模型卡在 0 字节、报 `401 ... xethub.hf.co` / `CAS Client Error`** | 镜像不支持 HF 的 Xet 加速。照抄：`python -m pip uninstall -y hf_xet` 然后 `export HF_HUB_DISABLE_XET=1 HF_ENDPOINT=https://hf-mirror.com`，再重跑第三步第 3 条 |
| `key 正常` 没出现 / 判分报 401 | 打开项目 `.env`，确认 `DEEPSEEK_API_KEY=` 后面是完整有效的 key，重跑第三步第 2、4 条 |
| 显存不足（CUDA out of memory） | 换更大显存的卡（32GB+），或联系技术同事 |
| 跑到一半窗口断了 | 重跑 `bash scripts/run_r2_batch.sh` —— 系统会断点续跑，不会重复计分 |
| 想先不花钱、只验证流程通不通 | 在**本地电脑**（不用 GPU）跑 `bash scripts/run_r2_batch.sh fake`，能出 agreement=1.0 就说明脚本链没问题 |

> 卡住超过两次、或看到不认识的红色报错：把终端最后 20 行截图发给技术同事，30 秒能判。
> 真正的 GPU 那步（第一~三步）如果实在生疏，找个会 Linux 的同事陪你过一次 15 分钟即可，之后你自己就能重复。
