## 二、新增 ≥3 级定界结论

**总判：补充轮未发现任何致命（4级）证据；C3/C4 的致命组合位在全部通道扫描后确认仍空置。** 6 条 ≥3 级/疑似 ≥3 级逐条定界如下（1、2 为侦察轮确认件，3–6 为补扫新警报）。

### 1. B2-01 → C3 三级重创·边缘型占位（R105，已全文定界）

- **占了什么**：任务成功率 + 真剂量曲线两要件。α 连续剂量（logit 对比 `z^sys+α(z^sys−z^def)`）在 IFEval strict 上倒 U（α∈[0.5,1] 峰、α=2 回落）、反能力人格 GSM8K Acc-Low 单调降（91.0→31.5→11.0）、RR^OOD 单调升；并给出**剂量-冲突律**（任务与助手先验冲突越大最优 α 越高）与 **steering tax**（Acc-High 也随 α 降）两条 ABCR 剂量设计必须直面的先验。
- **缺什么（= 不致命的理由，B2-01 全文定界报告核实）**：纯 logit 空间对比解码，**完全不触内部表征**，推理时必须有人格/系统提示文本；全文无任何激活转向 baseline；无统计检验/重复运行。S2 前向引文仅 4 篇全筛，无人把剂量化搬进残差流——**"残差流方向 × 剂量曲线 × 任务成功率"组合位仍空**。
- **对 C3 的动作**：卖点重定位并引 B2-01 + 同机制先行者 CoS（R111，2024，λ 剂量网格 + Spearman 剂量-反应检验）作为"解码层剂量族系"先行文献。

### 2. PANDA → C4 挤压（prox3 不致命）+ C1 强先行（R106，本轮全文补读）

- **占了什么**：agentic 域人格×任务交互面实证——16 人格（Big Five 高低极 + 黑暗三联）×25 text-games，Wilcoxon/Friedman 全套非参数检验；高 Openness 显著占优（vs 无人格 p=0.002、高 vs 低 p<0.001）+ 轨迹机制分析（更广探索、次短路径）。
- **缺什么**：干预为**训练时策略塑形**（人格分类器效价 γ·C 项 Q 塑形），非推理时人格文本/方向注入；无等长中性对照；单 γ 无剂量扫描。
- **对 C4/C1 的动作**：C4 的"agentic 域交互存在性"卖点已不可用（剩余活口 = 推理时干预 + 长程自适应条件选择 + 过程内调度）；对 C1 是动机件而非杀伤件。双托管漏检根因 = 查询角度而非托管渠道（偏倚2/4 交叉教训）。

### 3. duDmnRyJh5 → C3 致命位最近邻（R107，疑似3级，摘要级+repo日志定界）

- **三要素齐**：残差流方向（diff-in-means/SAE/hypernet 三法，L20 注入）× 剂量敏感（f∈{0,0.3,0.5,0.7,1.0}，AR 0.54→0.94 但 f=1.0 系过转向伪影；良性代价 f=0.7 仅 −4pp vs f=1.0 −26pp）× agent 任务结果（MCPTox tool-poisoning 基准）。
- **不判 3 级坐实的理由**：结果变量为**攻击防御率/良性 AR 而非任务成功率主口径**；无统计检验（50-prompt、单模型）；论文 PDF 被 OpenReview 人机 challenge 墙，剂量数字来自 GitHub 实验日志（与正式论文或有出入）。**待全文定界**。可直接偷：过转向伪影检测（思考块计数+补全长度坍缩）作剂量上界协议。

### 4. WVVSObO4oT → C3 疑似3级（R108，仅摘要级）

- 表示学习框架从多智能体交互轨迹学激活转向表示，推理时注入 → γ-Bench 博弈任务社会/策略性能跨模型族一致提升——**方向干预直链 agent 任务结果成立**；剂量操纵是否存在无法核实（OpenReview 墙 + 无 arXiv 版 + S2 未收录，本轮多渠道取全文未果）。**遗留核实项，混淆控制质量 0。**

### 5. GcpNaqxp0z → C4 致命位跟进（R109，疑似3级，前身 arXiv 已补读）

- 数值 Big Five 剂量 prompt 接口（前身版 0–100 四档，比例缩放 r>0.85）+ ARR 版新增**贝叶斯优化任务特定人格档案搜索**——正中 C4"系统交互 + 自适应条件选择"两要素。
- 定界：选择为 **query 级非过程内**、长程 agentic 域未覆盖、任务性能部分（贝叶斯优化）仅摘要级可判；ARR 匿名稿 PDF 被墙，前身 arXiv:2508.06149（Cho & Cheong）经 ar5iv 补读。

### 6. Peacemaker → C1/C4 prox3（R110，本轮全文精读）

- 谄媚人格 8 档 prompt 剂量 λ × 辩手组合网格（同质45/异质81）+ 法官独立扫描 → MMLU Pro/CommonsenseQA 客观准确率；NAR-SS r=0.902 的"人格→行为→结果"量化链；最优配置非单调（混合角色/全 troublemaker 胜一律低谄媚）。
- 定界：网格间差异无显著性检验、每配置单次运行未报方差、无等长中性对照——现象占位强、因果规范弱。
