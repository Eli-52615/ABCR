3. **CCL/NLPCC中文论文集未逐篇扫描**：CCL收中文论文且进ACL Anthology（如陈旭CCL2024中文智能体综述），严格说"中文发表但英文基础设施可达"。本轮抽查未见七主张相关实证，但2024/2025论文集(各百余篇)未穷尽。
4. **Semantic Scholar限流、本地arXiv索引失真**：英文版核验改用WebSearch/Exa完成，对2条prox 2候选与1条排除项做了定向核验；prox 1候选中3条学位论文因作者名不可得，只能标注"疑似无英文版"而非"确认"。
5. **ChinaXiv 心理学分区**只做了顺带触及（HEXACO预印本），未系统扫描其人格心理学分类下的LLM工作。

## ⑤ 主观概率估计："纯中文文献里还藏着≥3级证据"

**估计：约5%（低）。**

理由（基于本轮实际观察到的证据，非刻板印象）：

1. **直接观察：中文NLP社区的顶尖人格/角色扮演/转向工作全部走英文渠道。** 本轮命中的所有高质量本土工作——复旦RPLA综述(TMLR)、复旦CoSER(与阶跃星辰)、天大动态人格进化(ACL Findings 2025)、中科大IRiS(arXiv)、中科大/清华character-as-latent-variable(alphaXiv 2601.23081)、InCharacter(ACL 2024)——无一例外以英文发表；中文互联网上这些主题的内容全部是英文论文的转述（aclanthology.cn镜像、知乎解读、papernotes、机器之心报道）。C2/C3所需的机制干预类工作尤其如此：**中文语料里找不到任何一篇本土原创的激活转向实证**。
2. **直接观察：连中文心理学期刊的作者也在同步推英文版。**《心理科学》DeepSeek区域心理论文被本轮核验出英文arXiv版(2509.25283)——纯中文空间正在主动"漏水"到英文可达域。
3. **纯中文空间的实际产出形态与prox 3不符。** 本轮找到的纯中文实证（心理学报2篇）来自心理学系，用问卷/道德两难范式，不做agent任务与轨迹测量；纯中文工程论文（PIS）无行为实验且质量存疑；学位论文做的是测验生成/认知偏差。做"人格→agent任务结果"需要agent基础设施+行为评测习惯，而拥有这些的实验室（复旦/人大高瓴/清华/中科大）已被观察到惯例性发英文。
4. **残余风险来源（撑起那~5%）**：(a) CNKI付费墙后、摘要检索都触不到的长尾期刊与2025-2026届硕士论文——清华认知偏差论文证明"行为实验类"学位论文确实存在，同类中做人格×agent任务的个体论文可能存在但未被任何摘要索引露出；(b) 百度学术渠道缺口；(c) CCL/NLPCC中文短文未穷尽。但即使存在，此类工作大概率是单点小规模实验，构成"3级重创"（同问题+同结果变量+足以动摇主张优先性）的条件苛刻。
