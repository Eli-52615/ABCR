## 步骤 3.5:物化 `/Users/abcr-probe`(仅当步骤 3 报缺失)

现场实测:`sysadminctl -addUser` 只写目录服务记录,home 由 opendirectoryd 在首次
交互登录时物化;这些账户 shell=`/usr/bin/false`、Password=`*`,永不登录 → 永不
物化。**代码依据:只有 `/Users/abcr-probe` 是必需的**——安装器
`install_abcr_runtime.py` 对 `/Users/abcr-probe/Library` 用 `mkdir(parents=False)`,
父目录必须先在;其余 9 个身份的数据全在 `/Library/...` 或 `/Users/superagent/...`,
plist 的 `WorkingDirectory` 是 `/var/empty`,不需要 home。

不要用 `createhomedir`(会拷 User Template 模板目录,与 `abcr-human` 的 0700
精简形态不一致)。按 `bootstrap_abcr_human.sh` 的同形态创建:

```sh
sudo /bin/test ! -e /Users/abcr-probe && sudo /bin/test ! -L /Users/abcr-probe && echo "可创建" || echo "停:已存在或是链接"
```

```sh
sudo /bin/mkdir -m 0700 /Users/abcr-probe
sudo /usr/sbin/chown abcr-probe:abcr-probe /Users/abcr-probe
sudo /bin/chmod 0700 /Users/abcr-probe
```

```sh
sudo /usr/bin/stat -f '%Su:%Sg %Lp %HT %N' /Users/abcr-probe /Users/abcr-human
```

两行必须都是 `<user>:<group> 700 Directory`。其余 9 个 home 保持不物化是**有意的**
(最小面),已记入 ticket。下一个 release 起,accounts 脚本会自动物化,人工补救
不再需要。
