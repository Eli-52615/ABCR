## 步骤 3.5:一次性解锁 doctor 内部的 root git 访问(首次必做)

doctor 内部以 root 调 git 时会清空环境变量(丢掉 `SUDO_UID`/`HOME`),此时
git 的"dubious ownership"保护会拒绝 superagent 名下的仓库,报
`reviewed commit is unavailable or does not resolve exactly`。你手敲 `sudo git`
不报错是因为 sudo 保留了 `SUDO_UID`,git 对这种情况有豁免——doctor 里没有。
doctor 用的是 Homebrew git,它的系统级配置在 `/opt/homebrew/etc/gitconfig`。

先复现确认(模拟 doctor 的内部调用,预期报 dubious ownership):

```sh
sudo /usr/bin/env -i PATH=/usr/bin:/bin:/usr/sbin:/sbin LC_ALL=C \
  /opt/homebrew/bin/git -C /Users/superagent/shared-brain/ABCR/abcr \
  rev-parse --verify '1a7daf1eb231fe4216b0b97fd4a01e4598550315^{commit}'
```

确认后登记白名单(写 `/opt/homebrew/etc/gitconfig`,可用 `--unset` 撤销):

```sh
sudo /opt/homebrew/bin/git config --system --add safe.directory /Users/superagent/shared-brain/ABCR/abcr
```

再复现一次上面的 env -i 命令:这次必须打出完整提交号
`1a7daf1eb231fe4216b0b97fd4a01e4598550315`,才继续步骤 4。
