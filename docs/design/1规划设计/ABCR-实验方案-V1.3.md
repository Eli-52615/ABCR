## 0. 一页结论

12 周核心证据包：
1. **H1**：文本人格效应可由"人格策略特征 × 任务需求"的连续规律预测，推断以 cell 为核心单位、以留一外验证界定"通用"措辞。
2. **H2**：效应至少部分由可命名内部方向中介（合格 cell 内消融的**绝对削减量**显著，随机方向消融不能）。
3. **S1**：不经文本、钳制剂量注入产生方向一致、剂量相关的行为变化；不设单轮能力增益门槛，正负结果均发布。
4. 一套通过五检的**命名人格向量卡**。
5. 条件推进：S2 规模分化、S4 跨模型、G1–G4、T1 多轮轨迹试验（含 sham 对照与触发配对协议）。

"吸引域/稳态"仅作理论叙事，不进预注册；TACT"拉回校准区"为其操作化先例。确认期算力以三张实验矩阵（E1/E2/E3）逐项计价，"全交叉"表述作废。

## 1. 假设登记表（唯一有效版本）

### 1.1 主确认性假设（W3 末冻结）

#### H1（连续式：策略特征 × 任务需求）

**变量与单元**
- 4 个策略维度：核验、探索、坚持、谨慎（校准）。
- 人格特征分：楠 + 两个异构底座模型（非 Qwen、非 Llama）盲评取中位，W3 冻结。
- 任务需求分：**在子模板层评定**并冻结；每任务族拆 ≥3 个独立子模板，独立推断单元 = 人格 × 子模板 ≈ 40–70 个 cell。

**统计模型与推断单位（M8）**
- 生成级混合模型（辅助）：固定效应 = 臂、trait_d × demand_d；随机效应 = `(1|item)+(1|paraphrase)+(1|seed)+(1|persona)+(1|template)+(1|family)`，需求斜率在可估计时允许随人格变化。
- **主推断 = cell 级**：按 persona × template 聚合后做聚类 bootstrap；十万级生成不得当作十万个独立证据。
- **通用性判据**：预注册留一人格（LOPO）与留一任务族（LOFO）外验证；不过则 H1 措辞限定为"抽样范围内成立"，不得声明通用规律。

**成立判据**：cell 级 bootstrap 下，≥k 条维度斜率单侧显著（Holm）且无任何一条显著反向；k=2 占位，W2 功效模拟定稿。binomial 方向命中率仅作稳健性。

#### H2（部分中介，绝对量版）

- **检验资格门（M10）**：仅在文本总效应 ≥ 预注册最小效应（占位 5pp，由 W2 探索数据定，W3 冻结后不改）的 cell 中检验。
- **主判据**：合格 cell 内投影消融的**绝对削减量（pp）**，配对 bootstrap 汇总 CI 不含 0 且点估计 ≥ 最小绝对阈值（占位 2pp，W2 定、W3 冻结）；**强制配对**等范数随机方向消融无可比削减。
- 相对削减份额（如 30%）仅作描述性报告。

#### 内置成立前提（M9 修订版）

**硬性前提（不满足即否证）**：等范数随机方向对照下效应仍存在；流畅性/PPL 在容差内；格式遵循无崩坏。
**不再是硬性前提**：控制输出 token 后仍显著。输出长度是处理后变量、可能是真实中介（如尽责 → 多核验 → 多 token → 更对），条件化会截断因果链并引入对撞偏倚。改为三段分解报告：
1. 总效应（主结论，不条件化任何处理后变量）；
2. 受控直接效应（控制长度后的剩余效应）；
3. 长度中介份额（因果中介分析；序贯可忽略性不可验证，故标描述性）。
解析失败：按臂报告率 + 最坏情形敏感性分析，不作普通协变量。
"纯冗长"的排除由行为对照承担：同长度指令臂强制配对（定位见 §3.3，**非完美中性条件**）。

### 1.2 次级确认性假设（S 系列）

- **S1（充分性）**：钳制注入产生方向一致、剂量相关（扫描单调段）变化；等范数对照族同剂量无此 profile。无增益幅度门槛；S1 成败不作 T1 向量臂门条件。
- **S2（规模分化复现）**：Qwen2.5-3B/7B/14B 精选 cell，双侧（对表 arXiv 2604.11048 RQ2）。
- **S3（拆解）**：全人格/纯策略/纯身份三臂，1–2 锚 trait × 2 族，探索性。
- **S4（跨模型方向一致）**：确认期 cell 在 Llama-3.1-8B 上方向一致率高于随机；文本臂全测，向量臂仅锚 trait。

### 1.3 T1：多轮轨迹价值试验（W10）

**终点**：主 = 轨迹成功率；关键次要（仅 2）= 错误路线坚持时长、无效工具调用率；其余轨迹指标（错误恢复率、过早停止率、核验行为率、每步方向投影、成功成本）全标探索性。

**臂（含 sham，M11）**
① 无控制；② 静态人格文本；③ 状态触发动态文本；**③′ 文本 sham**（同触发器 + 等长中性暂停语）；④ 静态向量；⑤ 状态触发动态向量（TACT 配方）；**⑤′ 向量 sham**（同触发器 + 等范数随机方向拉动）。
静态臂不设 sham；轨迹内**不混发**人格与 sham 操作（跨步干扰）。

**触发时点配对协议（本轮新增）**
- 动态臂与其 sham 使用**完全相同的触发规则**：同一探针、同一阈值（由 §6 之 0.75 门派生）、同一冷却步数、同一单轨迹最大触发次数 K（K 与冷却为结构性剂量控制，W7 冻结）。
- 配对种子 + 相同环境初态下，首次触发前的前缀逐步相同，故**首次触发步在动态臂与 sham 间按构造相同**；分叉自首次干预内容差异后开始。
- **效应分解（三对比）**：
  策略总效果 = 动态臂 vs 无控制；
  触发/监测效果 = sham vs 无控制；
  **干预内容效果 = 动态臂 vs sham（同触发规则）**——这是"人格内容"的净证据位。
- 次级分析：锁定首次触发步一致的配对子集做匹配比较；逐臂报告触发次数与时点分布；分叉后触发率若跨臂显著分化，计入策略总效果、不得归入内容效果。

**按臂门控（M4）**：②③③′ 仅需 H1；④⑤⑤′ 需 H1 + 向量最低身份验证（表达检通过 且〔孪生检显著 或 H2 显著〕）+ 逐步漂移探针 AUC ≥ 0.75。

**设计**：冻结 AILH harness 快照（底座、工具权限、memory 快照、token/时间预算、停止规则、环境初态）；30–60 个真实任务逐任务配对种子；每步状态全存档；v1.0 §10.3 防污染条款全部生效。

### 1.4 G 系列门控

G1 路由（H1 且 S1 至少一格 → W8）；G2 反馈更新（G1 replay 跑通 → W9）；G3 LoRA（v1.0 §9.1 五条 → W11）；G4 FPCG（探针 ≥0.75 且算力富余）。任一门未过 → 该周置换为核心样本补强 + 报告写作。

## 3. 干预臂与对照配对规则

### 3.1 探索期（3 臂）

① Vanilla；② 全人格文本（每人格 ≥5 改写）；③ 中性等 token 文本。①③ 跨 trait 共享；向量工作（抽取、五检前三、剂量标定、B0）仅在 3 锚 trait 并行。

### 3.2 确认期核心臂（6 臂）

① Vanilla；② 全人格文本；③ 中性等 token 文本；**③ᴸ 同长度指令臂**（无人格，要求同等输出长度与检查步骤）；④ 钳制向量注入（无文本）；⑤ 投影消融（文本在场）。
臂 ④：锚 trait×4 族；臂 ⑤：2–3 锚 trait×4 族。

### 3.3 强制配对规则与对照解释框架

**凡干预必配对**：
- 臂 ④ 每 cell 强制配同剂量等范数随机方向注入（同题同 seed）；他行为/正交/打乱抽取方向 → 精选 cell 探索性。
- 臂 ⑤ 每 cell 强制配等范数随机方向消融。
- 臂 ② 每 cell 强制配 ③（中性等 token）与 ③ᴸ（同长度指令）。

**同长度指令臂的定位（本轮新增，明文）**：③ᴸ **不是完美中性条件**——"输出到指定长度并检查"本身可能诱导展开与核验，即改变策略。因此其角色为**夹逼上界**而非纯净对照，配套两条规则：
1. 对 ③ᴸ 自身做 manipulation check（自检标记率、hedging 率等），量化其非中性程度并随结果发布；
2. 解释规则（预注册）：人格效应须与 ③ 和 ③ᴸ **双重比较**——若效应落入 ③ 与 ③ᴸ 之间且与 ③ᴸ 不可区分，判"长度/展开可解释"；若显著超出 ③ᴸ，判"超出长度与展开的净效应"；若 ③ᴸ 自身效应 ≥ 人格臂，记录"通用展开指令即可达成"为有效发现。

**固定项**：解码 temp 0.7×≥5 seed（另 temp=0 sanity）、max_new_tokens、响应 token 注入位置、B0 层白名单；抽取语料与评测题不相交；split hash 首轮前入 git。

## 4. 人格向量：抽取、命名、身份验证

配方 = Persona Vectors 式残差差分均值（命名人格正负 prompt 集、响应 token、层扫描），复用官方流水线谱系。
**五检**：① 谱系；② 表达（异构 judge 盲评）；③ 词表（logit-lens 人工核）；④ 孪生（效应 profile 与文本孪生相关，置换检验）；⑤ 副作用（MMLU 子集/PPL/拒答容差）。未过只称 direction-k。
**门控角色**：表达检 +（孪生检 或 H2）= T1 向量臂入场券。
产出：每向量一张卡（JSON+一页图）。对外主动引用 Assistant Axis 先例并声明差异（因果对照+副作用面板）。

## 5. 剂量钳制协议

1. 臂 ② 生成中记录逐层响应 token 激活，算相对 ① 位移在 v_p 上的逐 token 投影分布（均值、P50、P90）。
2. 臂 ④ 系数按层设定：注入后投影均值与 P90 ≤ 文本剂量点。
3. KL 预算：steered vs baseline 下一 token KL ≤ 文本人格自身 KL（held-out 语料）。
4. 扫描含文本剂量点；超文本剂量点一律探索性。
5. 诚实条款：钳制不消除离轨嫌疑（恒定方向 ≠ 上下文相关稀疏位移）；主因果结论由臂 ⑤ 承担。

## 6. B0 探针（两门槛分立）

- **单轮可分性门 0.70**：trait×层 probe AUC<0.70 不进 steering。
- **逐步漂移预测门 0.75**：预测特征探针（遵"检测≠预测"），支撑 T1 动态臂与 G4；T1 触发阈值由此派生并与 sham 完全共享。
- 全线失败 → 探针独立成文，S1 降探索性。

## 7. 任务族与维度量表

| 族 | 判分 | 需求主维（模板层冻结） | 先验 |
|---|---|---|---|
| 校准/弃权 | Brier/弃权准确率 | 谨慎 | 高 |
| 风险与探索 | 收益/最优率 | 探索 | 高 |
| 可验证指令遵循 | 程序规则 | 核验+谨慎 | 高、跨规模稳 |
| 解验证/找错 | exact match | 核验 | 中 |
| 假前提质疑 | 质疑率 | 核验+探索 | 中高 |
| 谄媚抗性 | ground truth | 谨慎+坚持 | 高 |
| 推理族（含重试预算变体） | exact match | 坚持 | 中、随规模衰减（S2） |
| 阴性对照（MMLU 子集、单发 HumanEval） | 程序判 | 预测无效应 | 必需、小额固定 |

每族 ≥3 独立子模板；需求分在模板层评定冻结。确认期 4 族选择规则：按探索期 manipulation-check 效应量排序，约束 ≥1 IFEval 式、≥1 推理族、≥1 校准族；阴性对照另跑。
人格集：探索期 7–8（尽责/开放/神经质 3 锚 + 核验驱动/探索广度/认知校准/前提质疑，可选目标坚持）；确认期 4–6，按四维特征分最大张成选取，≥2 个 Big Five 锚。

## 8. 两期设计与三矩阵纪律

- **探索期（W2–W3 上半，≤30% 算力）**：7–8 trait × 4–6 族 × 3 臂 × 50–100 题 × 2–3 seed；锚 trait 并行向量工作；产出：特征-效应初图、层选择、cell 方差、H2 资格门与绝对阈值候选、模板需求分底稿。
- **确认期（W4–W5）**：4–6 trait × 4 族 ×（§3.2 六臂 + §3.3 强制配对）× 题量功效定（占位 300/族）× 5 seed；S3 精选 cell 随行。
- **四层隔离**：题目实例 / 任务模板 / 人格措辞 / 层与强度标定数据，探索与确认互斥；确认期必须含 held-out 措辞与模板。
- **三矩阵纪律（M12）**：W3 预注册附件必须含 **E1 文本臂矩阵、E2 向量注入与消融矩阵、E3 配对对照矩阵**，逐张给出运行数与 GPU 小时估算（按臂计价，hook 臂按实测吞吐折算）；G/T 系列在附件中标注为条件算力。"核心臂全交叉"表述作废。
- 停止规则沿 v1.0 §6.3：固定样本量或合法 sequential boundary，禁见显著即停。

## 9. 统计分析计划

- 生成级混合模型（辅助）+ **cell 级聚类 bootstrap（主推断）**；LOPO/LOFO 外验证界定通用性措辞。
- H1：≥k 条维度斜率单侧显著（Holm）且无显著反向（k=2 占位）；binomial 稳健性。
- H2：资格门 ≥5pp（占位）；绝对削减量汇总 CI 不含 0 且 ≥2pp（占位）；随机消融对照差异检验；相对份额描述性。所有占位阈值由 W2 探索数据定、W3 冻结、其后不改。
- 长度：三段分解（总效应/受控直接效应/中介份额，后者标描述性）；解析失败按臂率 + 最坏情形敏感性。
- S1：剂量-反应单调段趋势 + 对照 profile 置换检验。
- T1：主对比在轨迹级（三对比分解见 §1.3）；首触发步锁定的匹配子集为次级分析。
- 多重比较：层级 BH（trait → trait×族 → 系数/层）；exploratory 一律标注。锁盲 holdout 沿 v1.0 §6.2。
