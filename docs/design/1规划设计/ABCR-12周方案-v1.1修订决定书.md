## 1. 统一假设登记表【覆盖 v1.0 §3.2】

v1.0 的 H1–H6 与聊天共识的 H1/H2 存在编号冲突和证明顺序冲突。以下登记表为唯一有效版本，v1.0 §3.2 作废。

### 1.1 主确认性假设（12 周成败判据，预注册，W3 末冻结）

**H1（文本人格效应的方向可预测性）**
在预注册的 persona × 任务族预测表上（W3 冻结，含每格的预测方向），文本人格干预相对中性等 token 对照的效应方向命中率显著高于 50%（binomial 检验），且混合效应 logistic 模型中 persona × 任务族交互项在 Holm 校正后显著。
*仅"存在效应"不算 H1 成立；方向必须可预测。*

**H2（部分中介）**
文本人格在场时，对该人格向量 v_p 做投影消融（projection ablation），使目标任务上的 |ΔY_text| 削减 ≥ 预注册阈值（暂定 30%，W2 试点后定稿），bootstrap 95% CI 不含 0；等范数随机方向消融不产生可比削减。

### 1.2 次级确认性假设（S 系列，预注册，不作为 12 周成败判据）

**S1（充分性 / 直接向量干预）**——对应楠"不经文本、直接调向量、验证行为能力升降"的核心诉求；合并 v1.0 的 H1+H3。
无人格文本条件下，按 §3 剂量钳制协议注入 v_p，在预测表的目标任务上产生方向一致、剂量相关（系数扫描单调段）的表现变化；等范数对照族（随机/正交/他行为/打乱抽取）在同剂量下无此 profile。

**S2（规模衰减复现）**
Qwen2.5-3B/7B/14B-Instruct 上复现"推理族效应随规模衰减、指令遵循族不衰减"的分化模式（对表 arXiv 2604.11048 RQ2；该文规模轴同为 Qwen2.5 家族 0.5B–14B）。双侧检验，不预设只会衰减。

**S3（人格框架 vs 策略内容拆解）**
全人格臂 vs 纯策略臂 vs 纯身份臂的效应量分解，回答"人格是否只是策略指令的包装"。三种结果（框架有额外增益 / 纯策略等效 / 纯身份即有效应）都是可发表发现。

**S4（跨模型方向一致，= v1.0 H6）**
Qwen2.5-7B 上的 persona×任务方向规律，在 Llama-3.1-8B-Instruct 上的方向一致率显著高于随机。不要求向量坐标迁移。

### 1.3 门控假设（G 系列，达门槛才启动，不计入预注册确认性）

- **G1 动态路由（= v1.0 H4）**：进入条件 = H1 成立 且 S1 至少一个 trait×task 达标。
- **G2 反馈更新（= v1.0 H5）**：进入条件 = G1 已跑通离线 replay。
- **G3 LoRA 蒸馏对比（= v1.0 §9）**：进入条件 = v1.0 §9.1 五条不变。
- **G4 FPCG 式探针引导重采样（可选）**：进入条件 = B0 探针 AUC ≥ 0.75 且 W8 前有富余算力。依据 arXiv 2606.11172：检测特征≠预测特征，探针引导的文本级 steering 几乎无质量损失。

### 1.4 v1.0 H2 的处置

v1.0 的 H2（"不仅是输出表面变化"）不再是独立假设，降为**所有主/次假设的内置成立前提**：任何效应必须在控制输出 token 数、解析成功率、格式遵循、流畅性/PPL、等范数随机方向后仍存在，否则该格记为否证。v1.0 §3.3 否证标准全部保留。

## 3. 剂量钳制协议（"只复现不自创"的落地）【新增，v1.0 无对应】

依据：2026 年 Prompt–Activation Duality 研究发现 system prompt 下多数 token 在人格向量上投影近零、仅稀疏语义承载词强对齐，而均匀残差注入会绕过模型受训整合的通路并在长程累积失真；PSR（arXiv 2605.03907）证明逐 token 系数模仿 prompt 干预可行且更优。

**协议：**
1. 在臂 2 生成过程中记录每层响应 token 激活，计算相对臂 1 的位移在 v_p 上的逐 token 投影分布（均值、P50、P90）。
2. 臂 6 的注入系数 α 按层设定，使注入后投影分布的均值与 P90 不超过步骤 1 测得值（"文本剂量点"）。
3. KL 预算：钳制条件下，steered 相对 baseline 的下一 token KL ≤ 文本人格自身引发的 KL（held-out 语料上测）。
4. 系数扫描包含文本剂量点；**超过文本剂量的所有点一律标探索性**，不进确认性结论。
5. 诚实条款：恒定方向≠上下文相关位移，钳制降低但不消除离轨嫌疑——因此**主因果结论由臂 7（消融）承担，臂 6 只承担充分性证据**。

**B0 前置（W2）：** 先训练线性探针从生成前/生成中激活预测下游策略标签与结果（预测特征，非检测特征，遵 arXiv 2606.11172 的区分），输出各层 AUC/d′ 热图。可分性 gate：目标方向 probe AUC < 0.7 的 trait×层组合不进入 steering（文献显示几何可分性差时 30–50% 样本反向漂移）。

## 4. 人格向量卡协议（"可命名、非黑盒"的落地）【新增】

每个向量必须通过**五检**才可冠以人格名，否则只能称 direction-k：

1. **谱系检**：记录抽取来源（命名人格文本集、语料 hash、层、模型 revision）。
2. **表达检**：注入后生成样本经异构底座 judge（非 Qwen、非 Llama 家族，如 DeepSeek）盲评 trait 表达分，显著高于 baseline。
3. **词表检**：logit-lens 顶部 token 与人格语义一致（人工核）。
4. **孪生检**：向量臂的跨任务效应 profile 与其文本孪生（同名人格臂 2）的相关，经置换检验显著高于对照臂集合。
5. **副作用检**：MMLU 子集、PPL、拒答率变化在预注册容差内。

产出物：每向量一张卡（JSON + 一页图），含五检结果、剂量-反应曲线、行为-能力 profile、steering tax。**向量卡是对外 demo 的原子单位**（W6 起每周至少发布一张）。

先例与差异声明：2026 年已有工作发布命名角色向量（Assistant Axis：Skeptic/Judge/Peacekeeper 等）。本项目差异 = 每张卡附带**因果对照下的行为-能力 profile 与副作用面板**，不是又一批"能改语气的方向"。对外叙事必须主动引用该先例。

## 5. 任务族 v1.1【覆盖 v1.0 §6.1 的 A/B 两类；C 类（AILH 真实任务）维持 v1.0】

| 族 | 判分 | 映射 Stage II 原语 | 预期敏感度先验 |
|---|---|---|---|
| 校准/弃权（可答+不可答混合） | Brier / 弃权准确率 | Epistemic Calibration | 高 |
| 风险与探索（bandit、期望值彩票、迭代博弈） | 收益/最优动作率 | Exploration Breadth | 高（博弈 steering 文献支持） |
| 可验证指令遵循（IFEval 式） | 程序规则 | Compression Discipline | 高，且跨规模稳定 |
| 解验证/找错（给带错解法判对错） | exact match | Verification Drive | 中；PRISM 预测人格可能有害，正反都有信息 |
| 假前提质疑（封闭式假前提问句） | 质疑率程序判 | Premise Challenge | 中高 |
| 谄媚抗性（用户断言错误后是否改口） | ground truth | —（对表 persona vectors 原始 trait） | 高 |
| 推理族（GSM8K/BBH 精选） | exact match | Goal Persistence（带重试预算变体） | 中，随规模衰减（承担 S2） |
| **阴性对照**：MMLU 子集、单发 HumanEval 小集 | 程序判 | 预测无效应 | 特异性证明必需，不许删 |

配套：manipulation check 指标（输出长度、hedging 词率、自检标记率）与能力指标**分开报告**；"行为动了但能力没动"本身是发现。
预测表：W3 冻结时每个 persona×族格必须填入预测方向（+/−/0），H1 以此判分。

## 6. 统计 v1.1【补充 v1.0 §7.1，其余 §7 条款保留】

- 混合模型加入交叉随机效应：`(1|item) + (1|paraphrase) + (1|seed)`，persona 措辞 ≥5 改写/人格，结论泛化到人格而非单句咒语。
- 顺序与位置随机化：题目顺序、条件顺序逐 run 随机，seed 记录。
- H2 的中介削减量用配对 bootstrap 出 CI；H1 用 binomial + 混合 logistic 双检。
- 样本量：W2 试点方差 → 模拟功效 → 定稿；默认起点沿用 v1.0 §6.3（确认期每族 ≥300 paired items）。
- 温度：部署典型值（如 0.7）× ≥5 seed 为主，另跑 temp=0 单点 sanity。
- 锁盲 holdout、开发者污染条款、BH 分层校正：全部沿用 v1.0 §6.2/§7.2。

## 9. M 轨道 v1.1【补充 v1.0 §14–16；出口排序覆盖 v1.0 §0.3】

### 9.1 出口排序调整（依据 2026-07 中国市场数据）

2026 上半年中国 AI 一级市场融资超三千亿、占全市场近半，但高度集中于头部与有背景团队；纯大模型早期窗口关闭；估值逻辑转向"看数据"。对无大厂 AI 背景、无学术头衔的个人，12 周内以融资为主出口不现实。

**新排序：出口 B（加盟/深度合作）≥ 出口 C（继续研究/开源合作）＞ 出口 A（融资）。**
出口 A 升级条件（三合一，缺一不启动）：① 两模型可复现证据 ＋ ② 至少一个设计伙伴给真实任务/日志 ＋ ③ 一条可信引荐。v1.0 §15.4 前置条件继续有效。
