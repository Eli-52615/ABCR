## 0. 一页结论

12 周做成的核心证据包：

1. **H1**：文本人格干预对任务表现的效应，可由预注册的"人格策略特征 × 任务需求"连续模型预测（不是找一个胜出人格）。
2. **H2**：该效应至少部分由可命名的内部人格方向中介（文本在场时投影消融显著削减效应，随机方向消融不能）。
3. **S1**：不经文本、按文本剂量钳制直接注入向量，产生方向一致、剂量相关的行为变化——**不设单轮净能力增益门槛**，正负结果均可发布。
4. **一套通过五检的命名人格向量卡**（对外 demo 原子单位）。
5. 条件推进：规模衰减复现（S2）、跨模型一致（S4）、路由/反馈/LoRA（G 系列）、多轮轨迹价值试验（T1，W10）。

理论叙事（"高能力人格吸引域/稳态调节"）仅用于解释与对外表达，**不进入任何预注册假设**；TACT 的"拉回校准区"作为其操作化先例引用。

## 1. 假设登记表（唯一有效版本）

### 1.1 主确认性假设（12 周成败判据，W3 末冻结）

**H1（连续式：策略特征 × 任务需求）**
预注册 4 个策略维度：**核验、探索、坚持、谨慎（校准）**。
- 每个人格在 4 维上的特征分：由楠 + 两个异构底座模型（非 Qwen、非 Llama 家族）盲评，取中位，W3 冻结。
- 每个任务族在 4 维上的需求分：同法评定，W3 冻结。
- 主检验：混合效应模型中 `trait_score_d × task_demand_d` 交互斜率的单侧检验（方向预注册：特征-需求匹配 → 增益），Holm 校正后 **≥ k 条维度显著且无任何一条显著反向**。k 暂定 2，由 W2 功效模拟定稿。
- 稳健性检验（降级，不作判据）：预测表方向命中率 binomial（12 格设计下需命中约 10 格才显著，过苛，故降级）。

**H2（部分中介）**
文本人格在场时，对 v_p 投影消融使目标任务 |ΔY_text| 削减 ≥ 30%（占位，W2 试点后定稿），配对 bootstrap 95% CI 不含 0；**强制配对对照**：等范数随机方向消融无可比削减。

**内置成立前提（原 v1.0-H2，适用于所有假设）**：任何效应须在控制输出 token 数、解析成功率、格式遵循、流畅性/PPL、等范数随机方向后仍存在，否则该格记否证。v1.0 §3.3 否证标准全部保留，另增：钳制剂量点上 S1 全不显著 → 记"文本通路优于均匀注入"的有效负结果。

### 1.2 次级确认性假设（S 系列，预注册，不作成败判据）

- **S1（充分性）**：无文本条件下按 §5 钳制协议注入 v_p，目标任务出现方向一致、剂量相关（扫描单调段）的变化；等范数对照族同剂量无此 profile。**不要求增益幅度门槛**；S1 成败**不作为** T1 向量臂的门条件（门条件见 §1.4）。
- **S2（规模分化复现）**：Qwen2.5-3B/7B/14B 精选 cell 上复现"推理族效应随规模衰减、指令遵循族不衰减"（对表 arXiv 2604.11048 RQ2）。双侧。
- **S3（拆解：人格框架 vs 策略内容 vs 身份）**：探索性精选 cell（1–2 个锚 trait × 2 族），三臂对比，标探索性。
- **S4（跨模型方向一致）**：确认期 cell 的效应方向在 Llama-3.1-8B-Instruct 上的一致率显著高于随机；文本臂全测，向量臂仅锚 trait。

### 1.3 T1：多轮轨迹价值试验（W10，独立门控）

**主终点**：轨迹成功率。**关键次要终点（仅 2 个）**：错误路线坚持时长、无效工具调用率（对应 TACT 过思/过动两轴）。其余轨迹指标（错误恢复率、过早停止率、核验行为率、每步方向投影、成功成本）**全标探索性**。

**臂**（4–5 个）：① 无控制；② 静态人格文本；③ 状态触发动态文本（逐步探针 → 条件注入纠偏指令）；④ 静态向量；⑤ 状态触发动态向量（TACT 配方：逐步探针 + 条件拉回校准区）。

**按臂门控（M4）**：
- 臂 ②③：仅需 H1 成立。
- 臂 ④⑤：H1 成立 + 向量最低身份验证（表达检通过 **且**〔孪生检显著 **或** H2 显著〕）+ 逐步漂移探针 AUC ≥ 0.75。
- 身份验证在单轮**行为层**完成——放弃的是单轮能力增益门槛，不放行为身份验证。

**设计**：冻结 AILH harness 快照（底座、工具权限、memory 快照、token/时间预算、停止规则、环境初态）；30–60 个真实任务，逐任务配对种子；每步状态全存档；v1.0 §10.3 防污染条款全部生效（confirmatory 期关自修改、auditor 盲条件、禁逐题修 prompt）。

### 1.4 G 系列门控扩展

- **G1 路由**：H1 成立 且 S1 至少一格达标 → W8 启动（Router 阶梯按 v1.0 §8）。
- **G2 反馈更新**：G1 离线 replay 跑通 → W9。
- **G3 LoRA 蒸馏对比**：v1.0 §9.1 五条不变 → W11。
- **G4 FPCG 式探针引导重采样（可选）**：B0 探针 AUC ≥ 0.75 且 W8 前有富余算力。
- 任一门未过：该周置换为 H1/H2/S 系列样本量补强 + 报告写作。

## 3. 干预臂与对照配对规则

### 3.1 探索期臂（3 臂）

① Vanilla；② 全人格文本（每人格 ≥5 改写）；③ 中性等 token 文本。
①③ 跨 trait 共享。向量工作（抽取、表达检、剂量标定、B0 探针）仅在 3 个锚 trait 上并行进行。

### 3.2 确认期核心臂（5 臂）

① Vanilla；② 全人格文本；③ 中性等 token 文本；④ 钳制剂量向量注入（无文本）；⑤ 投影消融（文本在场）。
- 臂 ④：锚 trait（3 个）× 4 族；臂 ⑤：2–3 个锚 trait × 4 族。

### 3.3 强制配对对照规则（对 v1.1 十臂制的预算化取代）

对照不再全交叉，改为**凡干预必配对**：
- 每个臂 ④ cell 强制配跑同剂量**等范数随机方向注入**（同题同 seed）；等范数他行为方向/正交方向/打乱抽取方向在精选 cell 上跑，标探索性。
- 每个臂 ⑤ cell 强制配跑**等范数随机方向消融**（H2 对照，不可省）。
- 长度/计算控制：以统计控制为主（输出 token 协变量 + 长度受控分析双报告）；"同长度指令"行为臂降为精选 cell 探索性。

### 3.4 固定项

所有臂固定解码参数（temp 0.7 × ≥5 seed，另 temp=0 单点 sanity）、max_new_tokens、注入位置（响应 token）、层白名单（B0 选定）。抽取语料与评测题**不相交**；split hash 首轮前提交 git。

## 4. 人格向量：抽取、命名、身份验证

**配方**：Persona Vectors 式残差流差分均值（命名人格正负 prompt 对比集，响应 token 位置，层扫描），复用官方流水线谱系（PERSONA/ICLR 2026 已验证其可复用性）。

**五检（冠名前置条件）**：① 谱系检（抽取文本集、语料 hash、层、模型 revision）；② 表达检（异构 judge 盲评 trait 表达分显著高于基线）；③ 词表检（logit-lens 顶部 token 语义一致，人工核）；④ 孪生检（向量臂跨任务效应 profile 与同名文本臂相关，置换检验过阈）；⑤ 副作用检（MMLU 子集、PPL、拒答率在容差内）。未过五检只称 direction-k。

**身份验证的门控角色**：表达检 +（孪生检 或 H2）= T1 向量臂入场券（§1.3）。

产出：每向量一张卡（JSON + 一页图：五检、剂量-反应、行为-能力 profile、steering tax）。对外须主动引用 Assistant Axis 命名角色向量先例并声明差异（因果对照 + 副作用面板）。

## 5. 剂量钳制协议（"只复现不自创"）

1. 臂 ② 生成中记录逐层响应 token 激活，算相对臂 ① 位移在 v_p 上的逐 token 投影分布（均值、P50、P90）。
2. 臂 ④ 系数 α 按层设定：注入后投影均值与 P90 不超过步骤 1 测得值（"文本剂量点"）。
3. KL 预算：steered vs baseline 的下一 token KL ≤ 文本人格自身引发的 KL（held-out 语料）。
4. 系数扫描含文本剂量点；**超文本剂量的点一律标探索性**。
5. 诚实条款：钳制降低但不消除离轨嫌疑（恒定方向 ≠ 上下文相关的稀疏位移，见 Prompt–Activation Duality）；主因果结论由臂 ⑤ 承担，臂 ④ 只承担充分性。

## 6. B0 探针（两个门槛，勿混）

- **单轮可分性门（0.70）**：trait 方向线性 probe AUC < 0.70 的 trait×层组合不进入 steering（几何可分性差时 30–50% 样本反向漂移）。
- **逐步漂移探针门（0.75）**：从生成前/中激活预测下游策略与结果的**预测特征**探针（遵 arXiv 2606.11172 检测≠预测之分），AUC ≥ 0.75 方可支撑 T1 动态臂与 G4。
- B0 全线失败 → 探针研究独立成文，S1 降探索性。

## 7. 任务族与维度量表

| 族 | 判分 | 需求主维（W3 正式评定冻结） | 敏感度先验 |
|---|---|---|---|
| 校准/弃权 | Brier / 弃权准确率 | 谨慎 | 高 |
| 风险与探索（bandit/彩票/迭代博弈） | 收益/最优率 | 探索 | 高 |
| 可验证指令遵循（IFEval 式） | 程序规则 | 核验+谨慎 | 高、跨规模稳定 |
| 解验证/找错 | exact match | 核验 | 中 |
| 假前提质疑 | 质疑率程序判 | 核验+探索 | 中高 |
| 谄媚抗性 | ground truth | 谨慎+坚持 | 高 |
| 推理族（GSM8K/BBH 精选，带重试预算变体） | exact match | 坚持 | 中，随规模衰减（承担 S2） |
| **阴性对照**：MMLU 子集、单发 HumanEval 小集 | 程序判 | 预测无效应 | 特异性必需，小额固定跑 |

**确认期 4 族选择规则（W3 预注册后执行）**：按探索期 manipulation-check 效应量排序，约束：≥1 高先验族（IFEval 式）、≥1 推理族（S2 连续性）、≥1 校准/弃权族；阴性对照始终另跑。

**人格集**：探索期 7–8 个 = Big Five 锚 3 个（尽责、开放、神经质）＋ AILH 功能原语（核验驱动、探索广度、认知校准、前提质疑，可选目标坚持）。确认期 4–6 个：按 4 维特征分**最大张成**选取（max-min 距离），约束 ≥2 个 Big Five 锚保文献可比。

## 8. 两期实验设计

### 8.1 探索期（W2–W3 上半，算力 ≤30%）

7–8 trait × 4–6 族 × 3 臂 × 50–100 题 × 2–3 seed（vLLM 批量）；锚 trait 并行做向量抽取、五检前三项、剂量标定、B0 两类探针。目标：特征-效应初图、层选择、方差估计、剂量点。

### 8.2 确认期（W4–W5）

4–6 trait × 4 族 × 5 核心臂（+ §3.3 强制配对对照）× 题量由功效模拟定（占位 300/族）× 5 seed。S3 精选 cell 随行，标探索性。

### 8.3 四层隔离（M6）

探索期与确认期在以下四层互斥：① 题目实例；② 任务模板；③ 人格措辞改写；④ 层与强度标定数据。确认期必须含 held-out 措辞与模板。探索期任何数据不得进入确认期检验集。

### 8.4 样本量与功效程序

W2 试点方差 → 模拟功效 → 定稿题量与 k；**功效模拟必须按臂计价**（hook 臂单价高于 vLLM 文本臂，按实测吞吐折算）；停止规则沿 v1.0 §6.3（固定样本量或合法 sequential boundary，禁"看到显著就停"）。

## 9. 统计分析计划

- 主模型：混合效应 logistic/beta；固定效应 = 臂、trait_score_d × task_demand_d、输出 token 数、解析成功；交叉随机效应 `(1|item)+(1|paraphrase)+(1|seed)`；题目/条件顺序逐 run 随机。
- H1：4 条维度斜率单侧检验，Holm，≥k 条显著且无显著反向；binomial 命中率作稳健性。
- H2：配对 bootstrap 出削减量 CI；随机方向消融对照差异检验。
- S1：剂量-反应趋势检验（单调段）+ 对照 profile 置换检验。
- 多重比较：层级 BH（trait 级 → trait×族 → 系数/层）；exploratory 一律标注。
- 锁盲：holdout 冻结后楠只看聚合分与预定义错误类别（v1.0 §6.2 开发者污染条款）。
