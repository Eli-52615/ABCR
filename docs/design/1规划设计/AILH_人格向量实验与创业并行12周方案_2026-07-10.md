# AILH 人格向量实验 × 创业/加盟并行总体方案

> 版本：v1.0  
> 日期：2026-07-10  
> 时间范围：2026-07-10 至 2026-10-04（12 周，含启动周末）  
> 适用条件：本人每周 6 天 × 8 小时；Mac mini M4 16GB + MacBook Air M2 16GB；Claude Opus 4.8 high 与 ChatGPT 5.6 Thinking 作为高强度协作工具；不新增单价超过 5,000 元设备；不以论文录用作为唯一成败标准。  
> 本方案依据：AILH 已上传的架构全景、理念演进档案和工程进展史，以及截至 2026-07-10 的公开研究与产业信息。

## 0. 一页结论

### 0.1 这 12 周真正要做成什么

不是一次性证明“AI 有人格”，也不是寻找一种普遍让模型变聪明的万能人格。

要做成的是一套可复现证据：

> **在运行时不加入人格文本的条件下，对开放权重模型内部的行为/人格相关激活进行直接干预，可以造成任务相关、剂量相关、可重复的能力升降；基于历史反馈选择干预方向和强度的动态路由，能够在未见任务上胜过无干预、人格提示和最佳静态人格。**

研究成果暂命名为：

# ABCR：Adaptive Behavioral Control Runtime  
## 自适应行为控制运行时

“人格向量”是 ABCR 的第一种行为控制原语，不是最终产品的全部定义。

### 0.2 为什么这样定义

截至 2026 年，已有研究已经直接在开放模型的 FFN 神经元或残差流中诱导 Big Five 人格，并观察到稳定、任务依赖的认知能力变化；动态人格路由能在部分 benchmark 上胜过最佳静态人格。[R1][R2] 同时，最新研究也说明静态、全局、固定强度的 activation steering 常有质量损失、特征耦合和任务失效问题，因此真正有价值的方向不是“找到一根神奇向量”，而是：

1. 找到可测量的行为控制原语；
2. 判断何时使用；
3. 决定使用多少；
4. 用现实反馈更新路由而不是随意重写全部框架；
5. 证明增益不是输出长度、更多计算、随机扰动或评价器偏好造成的。

### 0.3 三条结果出口同时成立

12 周结束时，不把成败押在单一出口上。

**出口 A：融资创业。**  
形成“agent 行为调控 + eval 反馈闭环”的开源技术证据、演示、设计伙伴反馈和清晰产品楔子。

**出口 B：加盟 AI 初创公司。**  
形成 Applied Research Engineer / AI Evaluation Engineer / Agent Reliability Engineer / Research Engineer 的高密度作品集。当前就业市场总体偏弱，但含 AI 技能的岗位逆势增长；数据分析岗位中 AI 相关要求尤其高。[R14] 对远程岗位而言，公开成果必须替代学历、名企 AI 经历和线下人脉成为信任凭证。

**出口 C：继续独立研究或合作。**  
获得可复现 repo、负结果、跨模型结果、潜在合作者和下一阶段研究问题，不依赖顶会 workshop 录用才能继续。

### 0.4 最重要的战略取舍

- **先做独立的 Persona Causal Rig，不直接在完整 AILH 上做首轮因果实验。**
- **先复现 NPTI/残差向量，再做自己的功能性行为向量。**
- **先改变运行时激活和路由策略，不先训练 LoRA。**
- **先证明任务相关增量，不追求全局平均分提升。**
- **先做 3B/7B，正式结果在 7B–9B；不从 SAE、32B、70B 或 MoE 起步。**
- **研究和对外接触从第一周同步进行，不等“做完再社交”。**
- **每周必须发布一个可直观看见的证据对象：图、演示、数据表、可运行版本或外部反馈。**

## 1. 行业与研究判断

### 1.1 研究窗口真实存在

2026 年《A Systematic Analysis of the Impact of Persona Steering on LLM Capabilities》使用 NPTI 在 FFN 层直接调节 Big Five 相关神经元，覆盖 Llama-3-8B、Mistral-7B、Gemma-2-9B、Qwen2.5-7B，以及 Qwen2.5 0.5B–14B，发现人格诱导会产生稳定、可复现、强任务依赖的能力变化；其简单动态路由在 GPQA、MuSR、MMLU-Pro 等任务上胜过最佳静态人格，但在 GSM8K、BBH 上不总是占优。[R1]

PERSONA 进一步显示，Big Five 相关向量能够从激活空间提取、缩放和组合；其动态控制在多模型上取得较强人格遵循，但“人格表达好”不等于“通用能力一定提高”，MMLU 等指标多为保持或轻微变化。[R2]

Steer2Adapt 把多个行为方向组成低维先验子空间，仅用少量样本为新任务寻找线性组合，并在 Llama-3.1-8B、Qwen2.5-7B、Mistral-7B 上测试。[R3] 这与本项目长期目标高度一致：不是每次重训模型，而是让 agent 根据任务与反馈选择行为控制配置。

### 1.2 但直接 steering 不是天然优于 prompting

2026 年研究指出，常见 activation steering 并不忠实模拟 prompt steering 的 token 级动态干预；学习 token-specific 系数的 PSR 能胜过传统 activation steering，并在部分任务上接近或超过 prompting。[R4]

另有研究发现：

- 不同 Big Five 方向存在几何和行为耦合，正交化不能完全消除跨特质影响，还可能削弱 steering；[R5]
- 用来检测已经发生行为的特征，未必能预测未来推理结果，直接 steering 可能损害输出质量；[R6]
- steering 是否有效可以通过熵、KL 对齐等内部信号部分预测，但仍需机制与黑盒结果联合验证；[R7]
- 心理 steering 的最佳强度必须在“语义校准 + 流畅性约束”下搜索，混合 prompt 与内部干预有时优于二者单独使用。[R8]

因此本项目不能以“内部更深，所以一定更真实、更强”为前提。必须把“内部干预优于文本干预”作为待检验假设。

### 1.3 产业窗口：可靠性、评价和持续改进比“人格”更容易成交

2026 年产业信号集中在三个方向：

1. 企业 AI 已从试验走向真实部署。a16z 汇总的样本中，29% 的 Fortune 500 和约 19% 的 Global 2000 已成为领先 AI 初创公司的付费上线客户。[R10]
2. agent 基础设施正在转向路由、状态、政策执行、观测与协调；投资者更关心可量化 ROI，而不是“AI 氛围”。[R11][R12]
3. AI eval/observability/continuous improvement 已出现 Respan、Lemma、Coval、Laminar、Confident AI 等公司，证明需求真实，也说明“再做一个日志和评分平台”没有足够差异化。[R9][R18]

所以你的创业叙事不能是：

> 我研究 AI 人格，希望让 AI 更像人。

而应是：

> 我建立了一套可因果验证的 agent 行为控制层：它从真实失败中学习，在不重训底座的情况下动态选择行为策略，并能够证明改进来自哪种干预，而不是 prompt 偶然性。

### 1.4 AILH 已有资产应怎样利用

AILH 已具备：

- Drive → Dispatch → Capability → Tool 四层管线；
- 结构化 task log；
- 记忆与经验治理；
- 独立 auditor；
- benchmark 硬规则与灰区评判；
- 自修改沙箱、回退和多轮工具协作；
- V_core / V_mutable 的人格治理结构；
- 真实任务审计、prompt 实验和人格一致性实验历史。

已有实验表明 V_mutable 迭代能提高人格一致性，Dispatch/Capability prompt 违反数可显著下降；同时也暴露了记忆二阶偏差、自评向量精度低、同底座审计盲区和数据污染问题。

这些资产适合作为：

1. **真实任务与失败轨迹来源；**
2. **第 10 周以后的 agent 集成场；**
3. **创业展示中的系统能力证据。**

它们不适合作为首轮人格因果实验的完整试验体，因为变量过多，难以区分人格、路由、记忆、工具和审计的贡献。

## 2. 总体架构：三条并行轨道

```text
轨道 R：研究证据
  Persona Causal Rig
  → 直接内部干预
  → 能力影响图谱
  → 动态路由
  → 反馈更新
  → LoRA/权重固化（可选）

轨道 P：产品与 AILH 集成
  ABCR API
  → AILH 行为控制接口
  → 真实 agent 任务
  → 观测、回滚、审计
  → 设计伙伴试用

轨道 M：市场与职业
  每周公开证据
  → 研究者/创始人/工程师反馈
  → 设计伙伴访谈
  → 融资或远程岗位材料
  → 第 6、10、12 周决策
```

三条轨道必须共享同一事实源，不允许为了融资说一套、为了研究说另一套。

## 3. 核心科学命题与预注册假设

### 3.1 核心术语

为避免“人格”概念无限膨胀，实验中使用三层定义：

**人格标签（psychological label）**  
Big Five 等外部理论标签，用于和现有论文对照。

**行为控制原语（behavioral control primitive）**  
可以测量、干预并影响任务轨迹的内部方向或神经元集合，例如探索、验证、坚持、校准、质疑。

**自适应行为策略（adaptive behavioral policy）**  
根据任务特征和历史反馈，选择原语、方向、层和强度的路由策略。

### 3.2 主假设

#### H1：直接内部干预效应

在相同模型、输入、解码、工具和上下文下，仅改变人格相关内部激活，可使至少一个预先指定任务族的正确率相对 baseline 出现可重复变化，且 95% 置信区间不跨 0。

#### H2：不仅是输出表面变化

内部干预对能力的影响在控制输出长度、生成 token 数、格式遵循、困惑度/流畅性、随机等范数方向之后仍存在。

#### H3：剂量与方向一致性

至少一个 trait-task 组合呈现有理论意义的剂量响应；正向和负向 steering 的变化方向可区分，且不过度依赖单一系数。

#### H4：动态路由优于静态人格

仅使用 calibration set 学得的路由策略，在完全 held-out 测试集上优于：

- 无干预；
- 最佳固定人格；
- 人格文本提示；
- 固定 activation vector；
- 随机路由。

#### H5：反馈更新有效且局部

依据任务结果更新“任务 → 行为控制配置”的路由策略，能提高下一批未见任务表现；不需要同时更新完整人格定义、全部 harness 或底座权重。

#### H6：有限跨模型迁移

在 Qwen2.5-7B 上发现的“trait-task 方向规律”，至少在 Llama-3.1-8B 或 Mistral-7B 上保持方向一致；不要求向量坐标直接跨模型复制。

### 3.3 明确否证标准

以下任一结果都必须被记录为有效负结果：

- 人格评分变化明显，但能力变化在控制长度和格式后消失；
- 只有单个 benchmark、单个系数、单个模型有效；
- 随机等范数方向产生同等增益；
- calibration 有增益，held-out 反转；
- 动态路由不优于简单“按 benchmark 固定人格”；
- 内部干预普遍不如文本提示；
- 正负 steering 均只导致输出质量下降；
- 量化模型有效而 BF16 不复现；
- LLM judge 喜欢 steered 输出，但确定性准确率不变。

负结果不会终止整个项目，它会决定产品定位从“增益控制”转为“行为诊断/风险控制”或转向加盟相关初创公司。
